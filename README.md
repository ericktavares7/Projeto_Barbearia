# ✂️ HairDay - Agendamento para Barbearia

Este é um projeto de gestão de agendamentos desenvolvido para consolidar conhecimentos em **JavaScript Moderno**, **Modularização** e **Consumo de APIs**. O projeto permite selecionar datas, visualizar horários disponíveis e realizar agendamentos em tempo real.

Este projeto faz parte da minha jornada de transição de carreira e foi desenvolvido com o suporte do curso de Full Stack da **Rocketseat**.

## 🚀 Tecnologias Utilizadas
* **JavaScript (ES6+)**: Lógica, módulos (Import/Export) e manipulação do DOM.
* **Webpack & Babel**: Automação do ambiente de desenvolvimento e transpilação de código.
* **Day.js**: Biblioteca utilizada para o tratamento e validação de datas.
* **JSON Server**: Utilizado para simular uma API REST e persistir os dados dos agendamentos.
* **CSS Flexbox & Grid**: Para um layout moderno e responsivo.

## 🛠️ Como Testar o Projeto Localmente

Como este projeto utiliza um ambiente de desenvolvimento moderno, precisas de seguir estes passos para ver funcionar:

 1.No seu terminal Clonar o Repositório
    
git clone https://github.com/ericktavares7/Projeto-Barbearia.git
cd Projeto-Barbearia

3. Instalar Dependências
Certifica-te de que tens o Node.js instalado e corre:

npm install

4. Iniciar a API (Banco de Dados Fake)
O projeto precisa da API para carregar os horários. Abre um terminal e corre:

npm run server
O servidor da API ficará disponível em http://localhost:3333

5. Iniciar o Frontend
   
Abre um segundo terminal e corre:

npm run dev

O site abrirá automaticamente no teu navegador através do Webpack Dev Server.
